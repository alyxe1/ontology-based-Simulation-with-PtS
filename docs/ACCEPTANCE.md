# 实机验收记录

验证日期：2026-11-06。操作系统 Windows；Plant Simulation **2606.0006**（文件版本 2606.6.3666）；ProgID **Tecnomatix.PlantSimulation.RemoteControl.26.6**；独立环境 **ontologysim / Python 3.12.15**。

软件包精确版本见 `requirements.lock.txt`、`conda-win64.lock.txt`、`frontend/package-lock.json`。没有更改许可证服务或强制指定许可证类型。当前登录用户实际成功创建／编辑原生对象、执行离散事件仿真并保存 `.spp`；这是实测能力，不是对其他机器许可证的保证。

| 验收 | 实测证据与判定 |
|---|---|
| 原生正确性 | `artifacts/acceptance/native-probe.json`：两件工件各加工 10 秒，实际完工时间 10、20 秒；原生出口 2、等待 0、占用 0。模型为同目录 `analytical-model.spp`。 |
| 原生内核与维护 | `kernel.json` 及 `tests/test_native_evidence.py`：逐工序核对原生时长；无设备重叠占用；维护在完成事件后开始，维护期间没有新开工；派工均符合资格。 |
| 三类真实接入 | `integration.json`：ERP 文件导入、MES HTTP、OPC UA 实际服务和订阅均有来源记录；协议聚合后的现场状态摘要与原生参考切片一致。 |
| 去重与异常 | 同一 MES 消息重复接收不增加事件；未知设备 ID 被拒绝并进入待处理区。 |
| 断连重连 | 重启本机 OPC 服务与订阅后保持事件游标和现场状态；重读最新变量并去重。 |
| 语义参与 | 修改 CNC02 的精度资格会改变 SPARQL 候选；精密钢件改派 CNC03 被拒绝；SHACL 拒绝一个工件两个位置。 |
| 公平比较 | 共同快照、共同工件—工序样本、共同 129600 秒终点；回放仅包含冻结游标前的接收事件。 |
| 保存／退出／重载／续跑 | 完整应用退出后，原生 PID 消失；重启后恢复状态摘要一致；FIFO 续跑的生产事件序列与终态均与连续运行相同。 |
| 可重复演示 | 重置产生新项目，自动归档旧现场；再次推进维护，状态摘要完全一致。 |
| 生命周期 | 暂停真实任务后继续；取消标记为 cancelled 且不存在成功结果；刷新只读／SSE，不触发新任务。 |
| 自动检查 | `pytest` 9 项通过：契约编译摘要稳定、能力变化、改派拒绝、SHACL 位置、固定样本、容差／队列顺序、跨项目去重、图重建隔离、原生事件证据。 |

状态浮点比较采用绝对容差 **1e-6 秒**；列表顺序、ID、工艺序号、队列和占用精确比较。仅比较终态产量不足以视为恢复成功，因此额外比较完整生产事件顺序。

三方案实测指标见 README；所有结果保存 `native.verified`、原生时钟、Drain 计数、设备占用和队列成员。失败与取消没有 `RunResult`。

前端生产构建已完成，图表资源本地打包。Vite 报告单个图表 bundle 较大（约 2.1 MB，gzip 约 628 KB），不影响本机离线演示；尚未做面向公网的分包和多用户容量优化。RDFLib 的内部旧接口弃用提示不影响当前通过的验证。

最终增量检查见 `artifacts/acceptance/release.json`：三种语义视图均返回完整有效的节点／边；未改变的现场复用同一快照；调整倍速不会意外继续已暂停数据源；同一来源 ID 的冲突内容被拒绝；“原生模型”入口能重建并核对当前现场。

实际浏览器检查覆盖工厂现场、三源记录、语义视图切换、方案结果、ECharts 甘特图以及从页面点击“重载并校验”。页面最终显示“工件位置、队列、占用与时钟一致”，图表页没有浏览器控制台错误。结果与恢复页面截图位于 `artifacts/screenshots/`。
