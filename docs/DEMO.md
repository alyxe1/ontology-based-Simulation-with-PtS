# 客户演示脚本

建议 8–12 分钟。打开 `start.cmd` 后访问 `http://127.0.0.1:8820`。先说明页面右上角“合成演示数据”：本机 OPC UA、MES HTTP 与 ERP 文件都真实运行，数据来自受控原生基准仿真的参考轨迹。

## 1. 从现场出发

交付时已准备好维护现场、三个结果与存档，可先浏览，也可点击“重置演示”从头走。重置会自动归档当前状态，旧项目和方案不会混入新项目。

点击“载入演示工厂”。后台使用 Plant Simulation 创建原生工厂并生成基准参考轨迹；完成后页面停在首个同步切片。期间任务栏显示真实构建、仿真阶段。

展示 6 台设备、3 种产品和 6 个订单。点击“继续数据源”可观察队列、工件和订单进度。这个按钮控制数据发布，不是控制原生方案任务。

车间布局标题栏可选择 60×、600× 或 3600× 发布速度，较长空闲间隔会压缩以便演示。暂停期间调整速度不会自动继续。

## 2. 展示接入与语义

进入“数据接入”，查看三类源、跨系统设备 ID 和时间单位转换。来源记录显示事件时间、接收时间、质量与原始 ID。“重连数据源”会重建本机服务和订阅，暂停在已确认游标；点击继续发布恢复。

“编辑工厂配置”可修改能力、工时、订单、班次和维护参数。先“校验配置”查看 SHACL 与资格结果；“应用并重建工厂”会归档当前演示后按新配置生成参考轨迹。演示过程中如只想查看配置，关闭即可。

进入“语义模型”，切换实体关系、影响路径、本体结构；点击节点查看属性、标准映射与最近观测来源。图是当前游标的可重建投影；“执行语义校验”展示真实校验结果。

关系图每个订单显示两件代表工件，避免 120 件工件同时展开影响阅读；完整数据始终保留在 RDF 和事件存档中。

## 3. 定位维护问题

点击“推进至维护事件”。发布器快速发布到首个维护边界并自动暂停：约 **01:04:03**，CNC01 刀具完成计数为 **8 / 8**，维护至约 **01:49:03**。

强调规则：触发维护前当前工件已经完成，维护期间不再开工。队列工件仍是现场事实，改派只作用于尚未开工工序。

点击“冻结现场”，进入“影响分析”。查看维护关联的工件与订单。资格区别：精密钢件只可在 CNC01 加工；通用钢件可去 CNC02；铝件精加工可去 CNC03。

在“验证单件改派”中选取精密钢件的待加工铣削工序并选择 CNC03，点击“校验资格”，演示具体拒绝依据。再选有资格的设备，显示约束通过。

## 4. 比较方案

点击“运行三个方案”。后台串行重建同一冻结现场，核对状态后执行 FIFO、改派 + EDD、改派 + EDD + 12 小时班次。

任务栏“暂停仿真／继续仿真／取消当前任务”控制原生任务；取消不会产生成功结果。页面刷新只重连状态，不提交重复任务。

进入“方案比较”，查看共同快照、统一统计终点、累计完工、准时订单、未完工订单、等待、平均在制和全部完工时间。点击一行，展示甘特图、订单交付明细、设备利用率和假设。

预期基准结果为 **79 / 120 / 120 件**。后两个方案都能交付 6 个订单，12 小时班次将全部完工时间从约 25.22 小时缩短到约 9.32 小时。展示的是此配置的真实结果，不预设每个改动都必然有优势。

## 5. 回放与恢复

“工厂现场 → 过程回放”展示已接收历史，可拖动时间轴和选择倍速；回放不改变现场、不读取未发布未来，也不启动原生仿真。“返回现场”结束回放。

点击“保存现场”，在“历史存档”中查看状态摘要并导出组合 ZIP。关闭页面和应用，运行 `stop.cmd`，再运行 `start.cmd`。选择“重载并校验”，等恢复任务完成，确认“工件位置、队列、占用与时钟一致”。然后可从恢复的现场创建新方案。

“原生模型”在任务运行中打开当前原生窗口；空闲时先冻结、重建并核对现场，再显示该原生模型。其显示时刻可能需要几秒才能到达目标快照，任务栏会报告恢复进度。

## 演示边界

- 设备视图显示由真实消息得到的逻辑状态，未制作 CAD 级三维场景。
- 工艺与预测样本是已知计划／假设，未来参考实际事件不会作为预测输入。
- 接口是本机受控演示，无真实工厂写回，无 LLM 调用。
- 单独 `.spp` 不包含 Python 的完整控制状态；恢复应使用工作台的组合存档。
- 关闭应用应使用 `stop.cmd`，避免直接结束进程后留下未知的 COM 状态。
